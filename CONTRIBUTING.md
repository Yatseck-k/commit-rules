# Contributing

Contributions should keep this repository focused on the `commit-rules` agent skill.

1. Describe the behavioral change or documentation improvement in an issue or pull request.
2. Preserve the `SKILL.md` frontmatter (`name` and `description`) and its read-only inspection workflow.
3. Test the instructions against a repository with staged changes, unstaged changes, and no changes. Do not create commits during these checks.
4. Update `README.md` when usage or installation changes.
5. Use Conventional Commits for commit messages, and describe what was verified in the pull request.

Keep examples generic and do not include credentials, private diffs, or AI attribution in generated commit messages.
